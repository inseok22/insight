# 한국공항공사 채팅 문서 안내

회사와 한국공항공사는 동일한 시연 채팅 코드를 사용합니다. 설정·메모리 제한·Trace 구조·검증 절차는 [공통 채팅 안내](demo-chat.md)를 참고하세요.

현재 작업은 회사의 실제 vLLM·Langfuse 연결 검증을 우선합니다. 한국공항공사 IP·프록시 적용과 최종 폐쇄망 패키징은 아직 실행하지 않았으며 [향후 KAC 패키징 체크리스트](kac-packaging-checklist.md)에 정리했습니다.

기존 링크 호환을 위해 이 안내 파일을 유지합니다. [KAC Nginx 참고 예제](kac-nginx-api.conf.example)는 회사의 실행 중인 Nginx나 아직 확인하지 않은 KAC 운영 설정을 대체하는 파일이 아닙니다.
